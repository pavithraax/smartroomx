# Inside SmartRoom-X

## The Problem

Most smart room automation systems only focus on switching appliances ON and OFF.

However, real smart environments also face wireless communication problems such as weak indoor coverage, unstable connectivity, and signal interference.

SmartRoom-X explores both automation and wireless reliability.

---

## Project Vision

SmartRoom-X is an ESP32-based intelligent room automation platform that combines:

- embedded systems
- IoT communication
- occupancy-aware automation
- RF optimization concepts

The goal is to create a smarter and more reliable indoor automation environment.

---

## Core Functionality

The system uses PIR sensors to detect occupancy and automatically control appliances through relay modules connected to the ESP32.

Room activity and device status can later be monitored through a wireless dashboard.

---

## RF Engineering Integration

Unlike typical automation projects, SmartRoom-X also explores wireless optimization through:

- 2.4 GHz antenna experimentation
- RSSI analysis
- future VNA characterization
- future SDR-based RF monitoring

The focus is not only automation, but dependable wireless automation.

---
